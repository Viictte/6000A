# 6000A-Project

| **Running the backend locally**                              |
| ------------------------------------------------------------ |
| 1. Install the Python dependencies listed in `project/backend/requirements.txt` (Flask, etc.). |
| 2. From the repository root, start the Flask server with:    |
|                                                              |
| python project/backend/app.py                                |
|                                                              |
| 3. Open `http://localhost:5000` in a browser to use the app. |
|                                                              |
|                                                              |
